# Flummox 0.0.1

The first public release of Flummox: a desktop app and command-line tool for
reducing the space installed games use while keeping their normal launcher
paths. Linux and Windows use different storage backends, with reversible
compression and controls for restoring ordinary files.

## Linux

- Discover games from Steam, Heroic, and Lutris, or add your own game folders
  and libraries, including locations such as `~/My Games`.
- Analyze installed content and compare compression presets before starting
  work. Savings predictions are labeled as estimates and depend on the game's
  files and the drive's existing compression.
- Apply transparent native compression on btrfs. Games remain ordinary files
  that the filesystem decompresses when read.
- Prepare and verify Maximum Space stores with zstd compression and chunk
  deduplication. Writable FUSE mounts retain the launcher's path and preserve
  game writes and launcher updates. Automatic recommendations require a local
  compatibility report matching the exact game build and installed content.
- Manage background jobs from the desktop or CLI. Supported jobs can be paused,
  resumed, canceled, or retried; closing the window leaves queued work with the
  coordinator. Maintenance for future installs and updates is opt-in.

## Windows

- Discover local Steam installs or select another game folder.
- Optimize NTFS files with Windows WOF/LZX compression and restore ordinary
  storage through the desktop app or CLI.
- Install per user with Start menu integration, upgrade support, and an
  uninstaller in Installed apps. A portable ZIP is available too.

## Downloads and installation

| System | Download or package |
| --- | --- |
| Linux Intel/AMD x64 | `flummox-0.0.1-linux-x86_64.tar.xz` |
| Linux ARM64 | `flummox-0.0.1-linux-aarch64.tar.xz` |
| Arch/CachyOS | `yay -S flummox-bin` or the attached `.pkg.tar.zst` |
| Windows x64 | `flummox-0.0.1-windows-x86_64-setup.exe` or the portable ZIP |
| macOS Apple Silicon | Homebrew cask or `flummox-0.0.1-macos-aarch64.zip` |

For Homebrew:

```sh
brew tap bybrooklyn/flummox
brew install --cask flummox
```

GitHub displays a SHA-256 digest beside each download. AUR and Homebrew verify
their archives against pinned hashes. Linux archives require glibc 2.39 or newer
and the GUI's system libraries; the Apple Silicon app requires macOS 14 or newer.
See [installation instructions](https://github.com/bybrooklyn/flummox/blob/main/docs/install.md).

## Validation and current limits

Native CI builds and tests passed on Linux x64/ARM64, Apple Silicon macOS, and
Windows x64. Installation checks cover Windows install/upgrade/uninstall,
Homebrew install/uninstall, and Arch install/upgrade/GUI startup.

This is an early release. Real-game launch, gameplay, patching, and restoration
qualification remains necessary for Maximum Space; passing fixture tests does
not establish compatibility with every game. Keep the original until you have
verified the compressed installation.

macOS currently provides the desktop shell and has **no compression backend**.
Windows currently supports Steam and manual folders; Maximum Space and Linux's
background maintenance are not available on Windows. Windows downloads have no
trusted publisher signature, and the macOS app is ad hoc signed without Apple
notarization, so operating-system approval may be required.

Report problems through [GitHub Issues](https://github.com/bybrooklyn/flummox/issues),
including your OS, Flummox version, storage type, and the operation involved.
