# Flummox 0.0.2

Flummox adds a shared desktop layout, background Windows jobs and opt-in
maintenance, alongside storage planning and interrupted-job recovery. Native
APFS compression makes the Apple Silicon app useful beyond the initial
release's desktop shell.

## Desktop workflows

- Overview, Games and one continuous Settings page replace the separate queue,
  drive and recovery pages. Jump links lead directly to each Settings section.
  Jobs are grouped as Running, Waiting, Needs attention and History.
- Page changes retain games, jobs, search and scroll positions. Clipped
  transitions follow navigation direction. Wheel steps ease briefly and stop
  without momentum; reduced motion and direct keyboard scrolling are available.
- Discovery runs in the background. Local artwork uses bounded background
  decoding and caching, fixed placeholders and optional local-file overrides.
- Add a single game folder or a collection such as `~/My Games`. Missing
  locations remain visible until their original drive returns.

## Windows background work

- Discover Steam, Epic, GOG and Heroic installations from local launcher data.
  One current-user worker owns the durable queue, so closing a window leaves
  background jobs running.
- Opt into maintenance separately for each location. The first scan establishes
  a baseline; later new or updated games can be queued automatically. Exclusions,
  paused work, running games, updaters and unavailable drives defer compression.
  Already-compressed unchanged files are skipped.
- Open, pause/resume and exit through the tray. Login startup is a separate
  opt-in. Upgrade and uninstall stop the owned worker before replacing files;
  uninstall removes this installation's startup entry.

## Storage and recovery

- Review additional disk requirements and safety headroom on each affected
  volume before starting a storage job. Requirements sharing a volume are
  combined. Workers check space again and reject changed destination volumes.
- See remembered games when their original drives are disconnected. Storage
  work waits for the matching drive; manual pauses and exclusions remain intact.
- Review interrupted jobs, retained originals, stores, and update layers in
  Recovery. Export local diagnostics explicitly. Verify an interrupted restore
  against its retained store and updates before closing its recovery record.
- Produce compatibility reports from the desktop app, recording game builds,
  baseline and compressed load times, actual allocation, launch, gameplay,
  updates, metadata, and restoration. Failed checks remain visible in reports.
  The form measures allocated bytes itself, and refuses where the filesystem's
  figure would be wrong.

## Upgrading from 0.0.1

Open the new version and it replaces the older background worker by itself,
provided no job is running and no Maximum Space game is mounted. Queue history,
locations, exclusions and reports carry over. 0.0.1 asked you to restart the
worker by hand or log out.

## Safety fixes

A source audit before this release found and fixed these, among smaller items
listed in the [audit record](https://github.com/bybrooklyn/flummox/blob/main/docs/security/2026-10-08-audit.md):

- Reclaiming the original copy of a Maximum Space game now verifies the whole
  store first. 0.0.1 deleted the original without rechecking it.
- Restoring after compacting updates could leave out the updates the compacted
  store had absorbed. Compaction now waits until the original is reclaimed.
- Restoring never writes through a link inside the game folder.
- A job's sandbox no longer reaches the background worker's own files.
- A Steam manifest cannot point a game at a folder outside its library.

## Native Mac storage

Native APFS compression and restoration preserve ordinary file reads. Staged
files are checked before atomic replacement, and journals retain the original
for interrupted replacements. Recovery restores the retained original only
when file and volume identities match. Hard links and unsupported files are
skipped. Native compression uses built-in macOS tools; Mac FUSE remains future
work. The app bundle also includes the command-line executable.

## Smaller, verifiable downloads

Linux packages exclude embedded debug information while CI retains matching
symbols separately. A probe of the initial Linux x64 archive shrank from 30.3 MB
to 8.75 MB by removing debug data alone; this release also adds code, so its
final size can differ. Compression features remain enabled.

Every release includes one signed manifest covering all binary downloads. Its
public key is printed below and committed in `packaging/minisign.pub`. The
manifest adds release authentication; individual checksum downloads remain
omitted. Mac bundles keep ad hoc signatures, and Windows keeps its per-user
installer and portable ZIP. Operating-system publisher signing and Mac
notarization are not included.

## Installation and qualification

Linux: `yay -S flummox-bin`, or extract the architecture-matching archive.
Mac: `brew install --cask bybrooklyn/flummox/flummox`, or install the app ZIP.
Windows: run the x64 installer, or extract the portable ZIP.

Real-game acceptance records are required before this tag can publish. Native
builds, fixture checks, and installer tests establish their tested behaviors;
compatibility claims apply only to the recorded game builds and configurations.
